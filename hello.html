mpi_hello.c

Every rank except 0 sends a greeting, and rank 0 receives and prints them in order.

  • What it does:
    • Every rank except 0 builds a greeting string and sends it to rank 0
    • rank 0 prints its own greeting, then receives and prints the others in rank order
    • Textbook reference: Section 3.1 and lecture 09, slides 13 to 22

23#include <stdio.h>
24#include <string.h> /* For strlen */
25#include <mpi.h> /* For MPI functions, etc */
26​
27const int MAX_STRING = 100;
28​
29int main(void) {
30 char greeting[MAX_STRING]; /* String storing message */
31 int comm_sz; /* Number of processes */
32 int my_rank; /* My process rank */
33​
34 /* Start up MPI */
35 MPI_Init(NULL, NULL);
Starts MPI. Every process runs this line.
36​
37 /* Get the number of processes */
38 MPI_Comm_size(MPI_COMM_WORLD, &comm_sz);
comm_sz = how many processes were started (mpiexec -n).
39​
40 /* Get my rank among all the processes */
41 MPI_Comm_rank(MPI_COMM_WORLD, &my_rank);
my_rank = this process's id, 0 to comm_sz - 1. This is the only thing that makes the processes behave differently.
42​
43 if (my_rank != 0) {
Same program in every process. The rank picks the branch.
44 /* Create message */
45 sprintf(greeting, "Greetings from process %d of %d!",
46 my_rank, comm_sz);
47 /* Send message to process 0 */
48 MPI_Send(greeting, strlen(greeting)+1, MPI_CHAR, 0, 0, MPI_COMM_WORLD);
Sends strlen+1 chars (the +1 is the '\0') to rank 0, tag 0.
49 } else {
50 /* Print my message */
51 printf("Greetings from process %d of %d!\n", my_rank, comm_sz);
52 for (int q = 1; q < comm_sz; q++) {
53 /* Receive message from process q */
54 MPI_Recv(greeting, MAX_STRING, MPI_CHAR, q, 0, MPI_COMM_WORLD, MPI_STATUS_IGNORE);
Waits for the message from source q, tag 0. Looping q = 1, 2, ... is why output is in rank order.
55 /* Print message from process q */
56 printf("%s\n", greeting);
Only rank 0 prints the workers' greetings. Workers never print.
57 }
58 }
59​
60 /* Shut down MPI */
61 MPI_Finalize();
62​
63 return 0;
64} /* main */

Follow the messages

All steps as a list

    • Things to notice as you step through:

      • Pick Rank 0, then Rank 2, and compare which lines stay lit
      • Change the number of processes and see how the loop on line 52 follows it

    • Output with mpiexec -n 4 ./mpi_hello:

      • The order is always the same, because only rank 0 prints and it receives from rank 1, then 2, then 3
      • If rank 3 sends first, its message waits until rank 0 asks for it
      • Lecture 09 slide 18 shows a different print on rank 0 ("Process 0 of 4 is ready to receive"); the file here does not

    • With one process (-n 1):

      • Only Greetings from process 0 of 1! is printed
      • The loop on line 52 runs zero times because comm_sz is 1

    • Things to be able to explain:

      • Number of messages: comm_sz - 1 sends and the same number of receives
      • Why they must match: a missing send leaves rank 0 waiting forever, a missing receive can hang or lose the message
      • Why the +1: without it the string has no terminator when it arrives, so printf("%s") can read past the end
      • Why source is q and not a wildcard: it forces the printed order, which is the next file's contrast
      • Textbook exercise 3.1 asks what happens with strlen(greeting) and with MAX_STRING as the send length
