MPI function reference

Look up any MPI function used in this course: what it does, its arguments, and the mistakes to avoid.

Setup and shutdown

  • MPI_InitStarts MPI. It must come before any other MPI call.
  • MPI_Comm_sizeFinds out how many processes are in a communicator.
  • MPI_Comm_rankFinds out which process this is, as a number from 0 to comm_sz - 1.
  • MPI_FinalizeShuts MPI down and frees what it was using.

Send and receive functions

  • MPI_SendSends a message to one other process.
  • MPI_RecvReceives one message. It waits until a matching message arrives.
  • MPI_SsendA send that does not return until the receiver has started a matching receive.
  • MPI_SendrecvSends one message and receives another in a single call, in a way that cannot deadlock.
  • MPI_StatusA struct that a receive fills in with details about the message it got.
  • MPI_Get_countTells you how many elements a received message contained.

Collective functions

  • MPI_BcastCopies data from one process to every other process.
  • MPI_ReduceCombines one value from every process into a single result on one process.
  • MPI_AllreduceLike MPI_Reduce, but every process gets the result.
  • MPI_ScatterSplits an array on one process and gives each process a different chunk.
  • MPI_GatherCollects one chunk from every process into one array on a single process.
  • MPI_AllgatherLike MPI_Gather, but every process receives the whole array.
  • MPI_BarrierMakes every process wait until all of them have reached the call.

No function matches that search.
