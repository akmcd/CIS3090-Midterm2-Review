Code

The course programs, line by line. Pick a rank to see only the lines it runs, then press Next step to follow the messages one send or receive at a time. Press the i button on a line to read its note. Every output shown was produced by compiling and running the code.

  • mpi_hello.cEvery rank except 0 sends a greeting, and rank 0 receives and prints them in order.
  • mpi_hello2.cThe same idea with wildcard receives and the status object.
  • mpi_SendRec.cThe trapezoidal rule using only MPI_Send and MPI_Recv.
  • mpi_Bcast.cThe same program using MPI_Bcast and MPI_Reduce.
  • heatDiffusionMpi.cThe heat diffusion program: halo exchange, Allreduce and Gatherv, rank by rank.
  • Hangs and mix-upsThree small programs that go wrong, and how to see why.
  • Trapezoid traceChange the inputs and see which slice of the interval each rank computes.

Trip-ups in the course zip

  • mpi_SendRec.c is the textbook's mpi_trap2.c, and mpi_Bcast.c is mpi_trap3.c. The comments inside still use the old names.
  • The makefile builds mpi_hello, mpi_SendRec and mpi_Bcast, but not mpi_hello2.
  • The trapezoid programs read from the keyboard, so pipe the input in: echo "0 3 1024" | mpiexec -n 4 ./mpi_Bcast
  • mpi_odd_even.c and the Warp example arrAdd.py were not in the project files, so the Read page uses the code from the slides for those.
